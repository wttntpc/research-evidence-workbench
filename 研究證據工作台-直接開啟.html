Literature map

文獻地圖

一個節點是一篇文獻；線段表示你在證據卡中記錄的引用關係。

核心文獻已取得推薦／未取得引用關係
尚無文獻節點新增證據並填寫「文獻鍵值」，地圖就會開始形成。

怎麼建立關係？

  1. 每篇文獻設定一個簡短的「文獻鍵值」，例如 wu-2025。
  2. 在「引用的文獻鍵值」填入它引用的文獻，以逗號分隔。
  3. 把最重要的文獻設為核心；尚未取得全文的推薦文獻設為未讀。

第二階段可接 OpenAlex，自動補候選引用關係；仍需人工確認是否為同一篇文獻。

跨電腦使用

Supabase 自動同步，JSON 保留自主備份

完成「雲端同步」設定後，研究文件與證據會存入您自己的 Supabase；未設定時仍可用 JSON 在電腦間交接。

  1. 平時登入 Supabase，變更會自動同步
  2. 定期下載完整 JSON，保留離線備份
  3. 遇到衝突先備份，再選擇本機或雲端版本

注意：雲端版本選擇與 JSON 匯入都可能取代目前本機內容；工具會先詢問，不會暗中覆蓋。
